# 🌸 Flora Shopy

## 📖 About the Project
Flora Shopy is a simple and responsive flower shop website created using HTML , CSS and JS. The project showcases an elegant floral-themed design where users can browse flower collections, explore products, read customer reviews, and interact through a contact section.

This project was developed to practice front-end development skills and create a visually attractive user interface with responsive design principles.

## 🔗 Live Demo

https://florashopy.netlify.app/

## 🚀 Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive website design
- Attractive flower shop landing page
- Featured flower products section
- Why Choose Us section
- Customer feedback section
- Contact form
- Smooth and clean UI design
